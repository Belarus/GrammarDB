# Файл вызначае іерархічнае дрэва граматычных катэгорый і іх значэнняў.
# Кожны радок (акрамя каментароў і пустых радкоў) прадстаўляе адзін вузел у дрэве тэгаў.
# Іерархія (укладзенасць) задаецца колькасцю пачатковых прабелаў (водступам).
# Большы водступ азначае, што вузел з'яўляецца даччыным адносна папярэдняга вузла з меншым водступам.
# Радкі, якія пачынаюцца з сімвала '#', а таксама пустыя радкі ігнаруюцца.
#
# Сінтаксіс радка:
#   [*]<Назва групы>: <код1>=<апісанне1>[; <код2>=<апісанне2>...]
#
# Элементы радка:
#   1. Водступ (прабелы): вызначае ўзровень укладзенасці ў дрэве.
#   2. Прыкмета парадыгмы '*': апцыянальная зорачка перад назвай групы.
#      Пазначае апошнюю катэгорыю, якая адносіцца да лексіка-граматычнай характарыстыкі (парадыгмы / лемы).
#      Усе наступныя (даччыныя) узроўні апісваюць граматычныя характарыстыкі канкрэтных словаформ.
#      Для кожнага поўнага шляху ў дрэве ад кораня да ліста павінна быць роўна адна пазнака '*'.
#   3. Назва групы (катэгорыі): тэкставае найменне граматычнай групы
#      (напрыклад, Часціна мовы, Склон, Лік, Род, Спражэнне і г.д.).
#   4. Двукроп'е ':': падзяляльнік назвы групы і спісу магчымых значэнняў.
#   5. Спіс значэнняў: пары праз кропку з коскай ';'. Кожная пара мае фармат:
#        <код>=<апісанне>
#      дзе:
#        <код>      - адзінкавы сімвал (char), літара ці лічба тэга (напрыклад, N, S, 1).
#        <апісанне> - расшыфроўка / назва значэння (напрыклад, назоўнік, адзіночны лік).
#
# Абмежаванні і правілы праверкі:
#   - На кожным поўным шляху тэга павінна быць роўна адна група з пазнакай '*' (мяжа парадыгмы).
#   - Назвы груп на адным шляху не павінны паўтарацца.
#   - Сімвалы-коды на адным узроўні пераходаў павінны быць унікальнымі.
#
